# נייבור / NAYBOR

אפליקציית Flutter לניהול חיי הבניין: כניסה עם Google, יצירה והצטרפות לבניין באישור מנהלים, לוח מודעות ובקשות, ניהול דיירים ושיתוף חניות בחינם. ממשק עברית/RTL בעיצוב Glass; הנתונים וההרשאות נשמרים ב־Supabase.

- [הפעלה, בנייה ובדיקות](app/README.md)

- [מצב המימוש והאימות](docs/implementation-readiness.md)
- [בדיקות הצטרפות עם הקוד CHECK](docs/check-building-testing.md)
- [הפצה לחברים ומיקום השרתים](docs/beta-distribution.md)
- [חניון ובדיקה בין חשבונות](docs/parking.md)
- [סכמת השרת ובדיקות SQL](supabase/README.md)

`main` מיועד לגרסה העדכנית. העבודה נעשית ב־`codex/building-app-planning`. מסמכי ה־PRD האחרים וצילומי המסך הישנים מתעדים את האב־טיפוס הקודם; האפיון המקושר למעלה גובר עליהם. קוד האב־טיפוס הקודם הוסר; המיגרציות שהוחלו ונתוני השרת הקיימים נשמרו.
